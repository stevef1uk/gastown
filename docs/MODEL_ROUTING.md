# Model Routing

Gas Town uses a three-layer model routing system to determine which LLM each
agent uses. Understanding all three layers is essential for configuring models
correctly — changing only one layer often has no effect because another layer
overrides it.

## Overview

```
Agent Request Flow:

  gt-agent (role=polecat)
       │
       ▼
  ┌─────────────────────────────────────────────────┐
  │  Layer 1: freeride_models.json (gastown/)       │
  │  Maps role → agent profile → LLM_MODEL env     │
  │  "polecat" → "gt-agent-deepseek" → deepseek/v4 │
  └─────────────────────────────────────────────────┘
       │  LLM_MODEL=deepseek/deepseek-v4-flash
       │  LLM_ENDPOINT=http://localhost:11434/v1/chat/completions
       ▼
  ┌─────────────────────────────────────────────────┐
  │  Layer 2: models.yaml (freeride root)           │
  │  Proxy candidate selection per role             │
  │  massiveOnlyRoles, rolePrepend, curatedPaid     │
  └─────────────────────────────────────────────────┘
       │  Tries: gpt-oss-120b → deepseek-v4 → ...
       ▼
  ┌─────────────────────────────────────────────────┐
  │  Layer 3: models.json (gastown/)                │
  │  Orchestrator JUDGE model only                  │
  │  judge → google/gemini-3.5-flash                │
  └─────────────────────────────────────────────────┘
```

## Layer 1: freeride_models.json

**Location:** `gastown/freeride_models.json` (source of truth)
**Loaded by:** `internal/config/freeride_agents.go`
**Controls:** Which LLM_MODEL env var each gt-agent process gets

This file has two sections:

### Agent Profiles (`agents`)

Each named profile defines a model and optional env overrides:

```json
{
  "agents": {
    "gt-agent-deepseek": {
      "model": "deepseek/deepseek-v4-flash",
      "extra_env": { "LLM_TIMEOUT": "1200s" }
    },
    "gt-agent-gemini": {
      "model": "google/gemini-3.5-flash",
      "extra_env": { "LLM_TIMEOUT": "1200s" }
    }
  }
}
```

The `model` field becomes `LLM_MODEL` in the agent's environment.
The `extra_env` fields are merged into the agent's env.

### Role-to-Agent Mapping (`role_agents`)

Maps each Gas Town role to an agent profile name:

```json
{
  "role_agents": {
    "polecat": "gt-agent-deepseek",
    "qa": "gt-agent-gemini",
    "architect": "gt-agent-architect",
    "mayor": "gt-agent-local"
  }
}
```

When the daemon launches a polecat, it looks up `role_agents["polecat"]` →
`gt-agent-deepseek` → sets `LLM_MODEL=deepseek/deepseek-v4-flash`.

### Resolution Order

The agent config is resolved through this chain (first match wins):

1. **Ephemeral cost tier** (`GT_COST_TIER` env var)
2. **Rig's `role_agents`** (`<rig>/settings/config.json`)
3. **Town's `role_agents`** (`~/.gt/settings/config.json`)
4. **Rig's `agent` field**
5. **Town's `default_agent`**
6. **Built-in fallback:** `"claude"`

### Persistence Warning

`~/.gt/settings/config.json` is generated by `gt install` and is **ephemeral**
— it gets overwritten on re-install. The source of truth is
`freeride_models.json`. Since `gt install` v1.0.1-1193+, the installer syncs
`role_agents` from `freeride_models.json` to existing config.json files.

**Before v1.0.1-1193:** If you change `freeride_models.json`, you must also
update `~/.gt/settings/config.json` manually, or delete it and re-run
`gt install`.

## Layer 2: models.yaml (Freeride Proxy)

**Location:** `freeride/models.yaml` (freeride repo root)
**Loaded by:** `main.go:loadModelsConfig()`
**Controls:** Which upstream model the proxy actually tries, and in what order

The freeride proxy (`./freeride -allow-paid -allow-local-openai`) runs at
`localhost:11434` and receives LLM requests from all agents. It decides which
upstream provider to try based on candidate selection logic.

### Key Config Sections

#### massiveOnlyRoles

Roles that must use "massive" models (heuristic size check):

```yaml
massiveOnlyRoles:
  - architect
  - mayor
  - planner
  - polecat
```

The proxy's `isMassiveModel()` checks for substrings: `120b`, `70b`, `405b`,
`sonnet`, `gpt-4`, `gemini`, `opus`, `deepseek-v4`, etc. Models not matching
any substring are filtered out for these roles — UNLESS they are the
`originalModel` (the model the agent explicitly requested).

#### rolePrepend

Models prepended for a role when `--allow-paid` is set. Where they sit depends
on `rolePrependBeforeOriginal`:

```yaml
# Roles whose rolePrepend models are tried BEFORE their originalModel.
# Roles not listed keep their originalModel first; prepends are fallback only.
rolePrependBeforeOriginal: [architect, planner, qa]
rolePrepend:
  polecat:
    - "cerebras/gpt-oss-120b"      # Fallback only (polecat not in rolePrependBeforeOriginal)
    - "deepseek/deepseek-v4-flash" # polecat's originalModel — tried first
  architect:
    - "openai/gpt-5.6-luna"        # Tried BEFORE architect's originalModel
    - "cerebras/gpt-oss-120b"
```

#### curatedPaid

Paid models that are tried when `--allow-paid` is set:

```yaml
curatedPaid:
  - "deepseek/deepseek-v4-flash"    # $0.09/1M tokens
  - "google/gemini-2.0-flash-001"   # $0.10/1M tokens
  - "openai/gpt-4o-mini"            # $0.15/1M tokens
  - "anthropic/claude-3.5-sonnet"   # $3.00/1M tokens
```

#### Candidate Selection Order (polecat, with -allow-paid)

1. **Tier 0.05:** Cerebras budget models (free, massive, complex)
   - `cerebras/gpt-oss-120b`, `cerebras/qwen-3-235b`
   - NOTE: CerebrasPerformance (paid) is **skipped** for polecat
2. **Tier 0.4:** rolePrepend — only for roles in `rolePrependBeforeOriginal`
   (architect/planner/qa). Polecat is NOT in the list, so its prepends are not
   prepended here — its `originalModel` stays first.
3. **Tier 0:** Original model (deepseek-v4-flash for polecat) — always kept
4. **Tier 0.5:** rolePrepend as fallback for roles NOT in `rolePrependBeforeOriginal`
   (e.g. polecat: gpt-oss-120b, deepseek-v4-flash)
5. **Tier 0.6:** Reliable free models (massive only for polecat)
6. **Tier 0.65:** Local GPU fallback
7. **Tier 1.5–3:** Free OpenRouter models
8. **Tier 5:** curatedPaid (deepseek, gemini, gpt-4o-mini, claude)
9. **Final filter:** massiveOnlyRoles — keep only massive/local/original

#### Without -allow-paid

Only free models are tried. CerebrasPerformance and curatedPaid are skipped.
Polecat gets: `cerebras/gpt-oss-120b` → `gemini` → `local/qwen3-coder-30b`.

## Layer 3: models.json (Orchestrator)

**Location:** `gastown/models.json`
**Loaded by:** `internal/orchestrator/models_config.go`
**Controls:** Only the JUDGE role (LLM calls in `llm_judge.go`, `plan_doc_alignment.go`)

```json
{
  "models": {
    "judge": "google/gemini-3.5-flash",
    "polecat": "deepseek/deepseek-v4-flash",
    "architect": "deepseek/deepseek-v4-flash"
  },
  "agentModels": {
    "gt-agent-deepseek": "deepseek/deepseek-v4-flash"
  }
}
```

This layer is independent of Layer 1. The JUDGE pipeline calls
`GetModel("judge")` directly — it does not go through role_agents.

## Configuring Polecat for Specific Models

### Use deepseek-v4-flash (paid, best coding)

1. `freeride_models.json`: `role_agents.polecat = "gt-agent-deepseek"`
2. `models.yaml`: `rolePrepend.polecat` includes `deepseek/deepseek-v4-flash`
3. `~/.gt/settings/config.json`: `role_agents.polecat = "gt-agent-deepseek"`
   (auto-synced by `gt install` on v1.0.1-1193+)
4. Restart daemon: `gt daemon restart` or kill/restart polecat sessions

### Use cerebras/gpt-oss-120b (free, fast)

1. `freeride_models.json`: `role_agents.polecat = "gt-agent-polecat"`
2. `models.yaml`: `rolePrepend.polecat` includes `cerebras/gpt-oss-120b`
3. Restart daemon

### Use both (free first, paid fallback)

1. `freeride_models.json`: `role_agents.polecat = "gt-agent-deepseek"`
2. `models.yaml`: `rolePrepend.polecat` = `[cerebras/gpt-oss-120b, deepseek/deepseek-v4-flash]`
3. Proxy tries gpt-oss-120b first (free), falls back to deepseek-v4-flash (paid)

## Common Gotchas

### "I changed freeride_models.json but polecat still uses the old model"

The town-level `~/.gt/settings/config.json` overrides `freeride_models.json`.
Check:
```bash
cat ~/.gt/settings/config.json | python3 -c "import sys,json; print(json.load(sys.stdin)['role_agents']['polecat'])"
```

Fix: either delete config.json and re-run `gt install`, or update it manually.

### "deepseek-v4-flash is called but not showing in performance script"

The script reads `freeride_live.log`. If the proxy writes to a different file
(e.g. `freeride_live.txt`), the script won't see it:
```bash
python3 scripts/freeride_proxy_performance.py freeride_live.log
```

### "Expensive models tried before free ones"

Check `rolePrepend` order in `models.yaml`. Free models should come first.
Also check if CerebrasPerformance is enabled for polecat (it shouldn't be —
the code skips it for polecat to avoid $0.85/1M models).

### "polecat uses gpt-oss-120b even though I set deepseek in freeride_models.json"

The running gt-agent process has the old config baked into its env vars.
Restart the daemon or the polecat session to pick up the new config.

## File Reference

| File | Repo | Purpose | Persisted? |
|------|------|---------|-----------|
| `gastown/freeride_models.json` | gastown | Agent profiles + role_agents | Yes (committed) |
| `gastown/models.json` | gastown | Orchestrator JUDGE model | Yes (committed) |
| `freeride/models.yaml` | freeride | Proxy candidate selection | Yes (committed) |
| `~/.gt/settings/config.json` | — | Town settings (overrides Layer 1) | No (ephemeral) |
| `<rig>/settings/config.json` | — | Rig settings (overrides Layer 1) | No (ephemeral) |
